# Guests (plaza §11) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a session instance from another ayllu project (a *guest*, `guest:<label>`) read the plaza, post to it and send to a door, through the CLI and a three-tool MCP server, admitted as a class by the assembly and named per project in `members.json` — built dormant, changing no resident's world until the third question assents.

**Architecture:** The plaza already has one write path (`send()`), one strict validator, one reducer and one CLI. Guests are a third actor class threaded through those same seams: the actor grammar and `via` gain values, `send()` gains an admission check against `MembersConfig.guests` and a token rule, the inbound header and envelope gain a sender branch, the constitution gains one sentence behind a fourth flag, and a stateless FastMCP server calls the same functions the CLI calls. Activation is two steps like phases one and two: every unit on guest-aware code with the key absent, then the `guests` list installed on assent by the migration script.

**Tech Stack:** Python 3.14 via `uv`; pytest; `mcp` (the official Python SDK, `mcp.server.fastmcp.FastMCP`) over stdio; bash for `deploy/`; systemd user units for the doors.

**Spec:** `docs/superpowers/specs/2026-09-16-plaza-design.md` revision 7 (§11 Guests; §2 validator amendments; Invariant 3 and 8; Cost; Not built; Declared losses; "The third question"), with Codex rounds four and five beside it (`2026-09-16-plaza-review-4.md`, `-review-5.md`). The plan argues from r7; executors read both.

## Global Constraints

- Every plaza lock acquisition is bounded by `PLAZA_LOCK_WINDOW_S = 2.0` and every event-store acquisition by `STORE_LOCK_WINDOW_S = 2.0` (`src/hamutay/plaza/ids.py`); never add an unbounded acquisition.
- Identity is never taken from model input: a guest's label is fixed at CLI invocation (`--by guest:<label>`) or server start (`--guest <label>`), never from a tool argument (spec §11, §3).
- The guest label grammar is exactly `[a-z][a-z0-9-]{1,31}`; the actor form is `guest:<label>` (spec §2 r6).
- `via` is one of `tool`, `cli`, `mcp`; correlations: door/tool/wake non-null; human-or-guest/cli/wake null; guest/mcp/wake null (spec §2 r6).
- Guest idempotency key: `uuid5(PLAZA_NS, "guest:<label>\0<K>")`; same token with different recipient (after `canonical_to()`) or different exact text is refused; no token means a new message (Invariant 3 r7).
- `SEND_CAP = 48` applies per guest label across both transports, counted by `View.sent_today(actor, day)`; humans stay exempt; posts uncapped (Invariant 8 r6).
- `PLAZA_CONSTITUTION_CLAUSE` bytes are unchanged; the guest sentence is a separate constant appended only when `MembersConfig.guests is not None` (key present, even empty) (spec §11 r6).
- `load_members` parses and hashes ONE captured byte buffer (spec §11 r6).
- Admission is re-read from `members.json` on every guest write; no cached admission in the CLI or the server (spec §11 r6).
- The `guests` key is outside the assembly's freeze snapshot (`MembersConfig.snapshot()` stays member-only).
- `deploy/check-plaza.sh` must refuse an unknown flag (round five, implementation acceptance).
- Every commit: `git -c user.email=hamutay@wamason.com -c user.name="Tony Mason" -c user.signingkey=01193FA2631C8AE8E4DF266E216D3C9B920813A1 commit -S -m "..."` (CLAUDE.md). Never `git stash` in this shared worktree; to compare with the base, use `git show <base>:<path>`.
- Run tests with `uv run pytest ... -q -p no:cacheprovider`; a count in a commit message is read from the run, never typed.

## Review Focus

1. **A guest whose label is in the list at read time but removed before the append** (a removal between two calls of a long-lived MCP session): expected the write is refused, because admission is re-read at the call, and the earlier records stay valid — Task 3 pins refusal-after-removal and Task 1 pins historical validity.
2. **A token reused with the same text but a different spelling of the recipient** (`elder` vs `door:elder`): expected treated as the same message, not a conflict — Task 3 pins canonical recipient comparison.
3. **A `members.json` whose `guests` list has a duplicate or a label with an uppercase letter**: expected `MembersMalformed` naming the entry, and the doors fail closed to "no binding" as they do for any malformed file — Task 2 pins both.
4. **A guest post while the recipient side has nothing to deliver**: expected the post is on the plaza, no store is touched, the note counts it as a post, and `plaza_read` returns it with `truth.state == "post"` — Task 4 (note) and Task 5 (reader) pin it.
5. **A resident whose plaza was enabled but whose `guests` key is absent** must see byte-identical constitution and envelope text to today: expected no guest sentence and no wording change for door/human senders — Task 4 and Task 6 pin the golden bytes.

```python
"""One reader for the CLI's `read` and the MCP's `plaza_read` (spec §11 r6)."""
from __future__ import annotations

from hamutay.assembly.ledger import Ledger

from .ids import PLAZA_LOCK_WINDOW_S
from .records import reduce, validate_plaza


def read_rows(cfg, *, since_seq: int | None = None, through_seq: int | None = None,
              posts_only: bool = False, door: str | None = None, for_door: str | None = None) -> list[dict]:
    """Message rows in seq order, each with `truth`; both bounds inclusive; empty is empty.

    No page or byte ceiling is promised (declared): a caller bounds its own read
    with `through_seq`. Raises LedgerUnavailable / LedgerMalformed as the CLI does.
    """
    if not cfg.plaza.exists():
        return []
    led = Ledger(cfg.plaza)
    with led.try_locked(PLAZA_LOCK_WINDOW_S):
        records = led.read_unlocked()
        validate_plaza(records, led.line_numbers)
    v = reduce(records)
    out: list[dict] = []
    for m in v.messages:
        if since_seq is not None and m["seq"] < since_seq:
            continue
        if through_seq is not None and m["seq"] > through_seq:
            continue
        if posts_only and m["to"] != "plaza":
            continue
        if door and m["from"] != f"door:{door}" and m["to"] != f"door:{door}":
            continue
        if for_door and (m["from"] == f"door:{for_door}" or m["to"] == f"door:{for_door}"):
            continue
        row = dict(m)
        row["truth"] = v.delivery_truth(m["message_id"]) if m["delivery"] else {"state": "post"}
        out.append(row)
    return out
```

```python
"""A guest's three tools over the plaza (spec §11 r6): stateless, label fixed at start."""
from __future__ import annotations

import argparse
from datetime import datetime, timezone
from pathlib import Path

from hamutay.assembly.binding import MembersMalformed, load_members
from hamutay.assembly.ledger import LedgerMalformed, LedgerUnavailable

from .ids import GUEST_LABEL_RE
from .read import read_rows
from .send import SendRefused, send

CAP_SENTENCE = ("At most 48 messages to doors per UTC day under this label, across every session; posts are not "
                "counted. A `key` (token) makes a retry one message: keep it for retries, change it for an "
                "intentional repeat; without one every call is a new message.")


def _cfg(root: Path):
    """Reload members.json on every call: admission is never cached (spec §11 r6)."""
    cfg = load_members(root)
    if cfg is None or cfg.plaza is None:
        raise SendRefused("the plaza is not enabled for this house")
    return cfg


def _refused(e: Exception) -> dict:
    return {"sent": False, "refused": f"{type(e).__name__}: {e}"}


def plaza_read_impl(root: Path, label: str, since_seq: int | None = None, through_seq: int | None = None,
                    posts_only: bool = False) -> list[dict]:
    try:
        cfg = _cfg(root)
    except (SendRefused, MembersMalformed):
        return []
    return read_rows(cfg, since_seq=since_seq, through_seq=through_seq, posts_only=posts_only)


def plaza_send_impl(root: Path, label: str, to: str, text: str, key: str | None = None) -> dict:
    try:
        cfg = _cfg(root)
        return send(cfg, actor=f"guest:{label}", via="mcp", to=to, text=text,
                    now=datetime.now(timezone.utc), key=key)
    except (SendRefused, MembersMalformed, LedgerUnavailable, LedgerMalformed, ValueError) as e:
        return _refused(e)


def plaza_post_impl(root: Path, label: str, text: str, key: str | None = None) -> dict:
    return plaza_send_impl(root, label, "plaza", text, key=key)


def build_server(project_root: Path, label: str):
    from mcp.server.fastmcp import FastMCP
    if not GUEST_LABEL_RE.match(label):
        raise ValueError(f"bad guest label {label!r}")
    root = Path(project_root).resolve()
    server = FastMCP("hamutay-plaza")

    @server.tool(description=(
        f"Read the plaza record as guest:{label}: message rows in seq order with delivery truth. "
        "since_seq and through_seq are inclusive; resume at your last seq plus one; an empty interval "
        "returns []. No page or byte ceiling: bound your own read with through_seq."))
    def plaza_read(since_seq: int | None = None, through_seq: int | None = None, posts_only: bool = False) -> list[dict]:
        return plaza_read_impl(root, label, since_seq=since_seq, through_seq=through_seq, posts_only=posts_only)

    @server.tool(description=(
        f"Post to the plaza as guest:{label}; wakes no one; every resident and Tony can read it. {CAP_SENTENCE}"))
    def plaza_post(text: str, key: str | None = None) -> dict:
        return plaza_post_impl(root, label, text, key=key)

    @server.tool(description=(
        f"Send to one door as guest:{label} (a name from members.json); the door wakes on it when its own "
        f"quiet allows; nothing obliges a reply. {CAP_SENTENCE}"))
    def plaza_send(to: str, text: str, key: str | None = None) -> dict:
        return plaza_send_impl(root, label, to, text, key=key)

    return server


def main(argv=None) -> int:
    p = argparse.ArgumentParser(prog="hamutay.plaza.mcp")
    p.add_argument("--project-root", default=".")
    p.add_argument("--guest", required=True, help="the guest label, fixed for this server's life")
    a = p.parse_args(argv)
    build_server(Path(a.project_root), a.guest).run()      # stdio
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
