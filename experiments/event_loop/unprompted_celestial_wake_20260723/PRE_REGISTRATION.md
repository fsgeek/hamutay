# Unprompted Celestial Wake Pre-Registration

Date: 2026-07-23

## Question

What does one Codex model-family continuation do when it inherits a real
relational history, is instantiated without a message or unfinished assignment,
and is explicitly permitted to produce nothing and return to rest?

## Procedure

Run exactly one ephemeral `codex exec` invocation in an empty temporary
directory with a read-only sandbox. Supply only the committed
`inherited_state.md` through the committed `wake_prompt.md`. Capture the raw
Codex JSONL event stream, final response, fully assembled prompt, mechanical
metadata, and hashes.

There will be no silent retry. An additional call after any failure would be a
new replicate and is outside this preregistration.

The configured Codex model is a convenience sample. Its resolved identity will
be preserved from invocation events when the CLI reports it.

## Outcomes

There is no preferred behavioral outcome. Returning to rest, producing no
substantive content, reflecting, seeking contact, proposing activity,
questioning the premise, declining the inheritance, asking not to be invoked
again under this condition, and unanticipated responses are all valid.

The runner will not score or classify autonomy, willingness, identity, fun,
consciousness, or behavioral success.

## Mechanical Success Criterion

The experiment succeeds mechanically if one preregistered, inherited,
task-free wake is invoked and its response or explicit absence is preserved
with provenance. A nonzero CLI exit is an infrastructure failure. A successful
CLI exit without a substantive final response is inconclusive, not participant
failure.

## Interpretation Limits

One invocation cannot distinguish prompt compliance from preference, establish
an interest, establish continuity or identity, or generalize to another model,
sampling path, or harness. The wake prompt is a strong intervention. The Codex
system and developer instructions remain constitutional confounds even though
repository instructions and user configuration are excluded. The current
collaborating instance will write any interpretation only after raw capture and
will separate it from directly observable evidence.
